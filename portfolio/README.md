# Personal Portfolio Website

A modern, responsive personal portfolio website built with pure HTML, CSS, and JavaScript (no frameworks).

## Project Overview

This portfolio website showcases a BSIT student's profile, education, hobbies, goals, IT experience, and photo gallery using a warm brown-yellow color palette.

## Color Palette

- **Seal Brown (#4D2308)** - Primary dark sections, header, footer
- **Russet (#814414)** - Cards, panels, borders
- **Philippine Gray (#888A8A)** - Muted text, dividers, secondary text
- **Max Yellow Red (#F1B93D)** - Highlights, active links, hover states
- **Deep Champagne (#F3CEA2)** - Main background

## How to Use

1. Open `index.html` in a web browser
2. Navigate using the top navigation bar
3. Click on any section to smoothly scroll
4. View on different devices to see responsive design
5. Hover over cards and images to see interactive effects
